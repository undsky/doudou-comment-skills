## 📖 技能使用指南

本技能库作为 **AI Agent 的多平台自动化互动与回帖助手**（支持 Antigravity、Claude Code、OpenCode 等）。

---

### 一、安装

在任何目标工程根目录下，通过命令行一键安装：

```bash
npx skills add undsky/doudou-comment-skills --yes
```

---

### 二、使用

直接用大白话告诉 AI 想要在哪个平台检索什么主题、回复什么内容即可：

```text
帮我在知乎搜索自媒体，找到相关文章并回复：https://zhuanlan.zhihu.com/p/2078843612532568622
```
